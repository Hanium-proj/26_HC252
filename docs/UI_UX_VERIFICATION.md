# UI/UX 개편 검증 · 2026-10-25

## 범위

대시보드, 영상 분석, 근거 시각화, AI 어시스턴트, 문헌 검색의 공통 레이아웃과 컨트롤을 개편했다. 실제 API와 데이터 경로는 유지한다.

- 불필요한 배경 텍스처와 점선 빈 상태 제거. 제목·설명·검사 선택·상태의 시각적 계층 통일.
- 키보드 조작 가능한 커스텀 listbox, switch, 접힘 패널, 슬라이더, 버튼, 입력창. Escape 닫기, 방향키 선택, 초점 복원.
- 드래그 업로드 영역, 검사 목록 로딩과 검색 결과 없음 안내, 상태 배지.
- 원본 영상 크기를 고려한 뷰어와 확대/레이어 수치, 보기 초기화. 해부학적 분할에서는 불필요한 CAM 선택 비활성화.
- 에이전트 추천 질문, 실제 검사 미리보기와 요약, 출처 패널, 읽기 쉬운 답변 서식, Enter 전송/Shift+Enter 줄바꿈/한글 조합 입력 처리.
- 대화는 검사 및 분석 버전별 메모리에 보관. 메뉴 이동 시 복원되며 새로고침 시 초기화. 임상 대화 내용을 브라우저 영구 저장소에 추가 저장하지 않는다.
- 페이지 진입, 메뉴 펼침, 토글, 버튼, 답변 표시의 짧은 모션. prefers-reduced-motion 반영.
- 반응형 CSS와 모바일 내비게이션 유지. 이번 검증은 데스크톱 인앱 브라우저에서 수행했으며 모바일 실기기 검증은 하지 않았다.

## 실제 검증

- ESLint 및 프로덕션 빌드(TypeScript 포함) 통과.
- git diff --check 통과.
- 활성 화면 코드에 border-dashed, 기본 select, 기본 details, checkbox 없음.
- 추천 질문 클릭 → 실제 SSE 답변 완료 → 실제 문헌 5건 표시 확인.
- Enter 후속 질문 전송 및 실제 답변 완료 확인.
- 생성 중 중지 → 중단 상태 표시 및 다시 입력 가능한 상태 확인.
- 메뉴 이동 후 이전 질문·답변·인용 출처 복원 확인.
- 커스텀 검사 선택창 열기/Escape 닫기 확인.
- 근거 레이어 방향키/Enter 전환 → 실제 PSPNet 마스크와 분할 지표, CAM 선택 비활성화 확인.
- 문헌 추천 검색어 → 실제 검색 → 4건 결과와 원문 링크 확인.
- 일치하지 않는 검사 검색어 → 결과 없음 안내 확인.
