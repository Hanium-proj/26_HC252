# 프로토타입 시연 영상 대본

응급실에서 올라온 이동식 흉부 X-ray 한 건을 영상의학과 판독의가 Chest AI로
판독하는 흐름을 처음부터 끝까지 따라간다. 케이스는 `PX-2026-0125`
(68세 남성, 급성 호흡곤란, 모델 출력 폐부종 81%). 총 3분 30초 안팎.

## 준비

- 주소: https://26-hc-252.vercel.app (production). 로컬이면 `cd frontend && npm run dev`
- Chrome 새 탭으로 시작 (상태는 탭별 sessionStorage 라 새 탭 = 초기 상태).
  이미 쓰던 탭이면 사이드바 맨 아래 **세션 초기화** 클릭
- 북마크바 숨김 (`⌘⇧B`), 확대 100%, 창 폭 1440 이상
- 녹화: `⌘⇧5` 화면 기록. 나레이션은 아래 문장을 그대로 읽어도 되고 요약해도 된다
- 스트리밍 · 분석 진행 중에는 마우스를 움직이지 않는다
- 실수하면 그 씬만 다시 찍지 말고 세션 초기화 후 처음부터 (상태가 이어지는 구조)

## 등장 인물과 상황

- 판독의: 정경훈 (영상의학과) — 화면 우측 상단 JK
- 환자: 한지** 남성 68세. 어젯밤부터 누우면 심해지는 호흡곤란과 하지 부종.
  심부전 · 고혈압 과거력. 산소포화도 88%, 호흡수 28, 맥박 112, 혈압 168/98.
  응급실에서 이동식 앙와위 AP 촬영
- 모델: CXR-NET v2.4 — 폐부종 81% · 심비대 63% · 폐 음영 58% · 흉수 41%

> 대상입니다. 오른쪽 판독 요약은 초안이고 최종 판단은 판독의가 합니다.

액션 3: 툴바 AI OVERLAY 에서 **히트맵** 클릭.

화면 반응: 왼쪽 필름 위에 모델의 Grad-CAM 이 올라오고 외곽선 두 개가 근거 영역을
감싼다 (실선 = 확신 90% 초과, 점선 = 50-90%).

나레이션:
> 근거 영역이 양측 폐문부에 대칭으로 잡힙니다. 오른쪽은 폐 분할 마스크로 폐 영역만

### 턴 1 — 감별 진단

액션: 입력창에 타이핑 후 Enter.

```
68세 남성, 야간 발작성 호흡곤란과 하지 부종으로 응급실 내원. 양측 폐문부 중심 음영과 심비대가 보이는데 심인성 폐부종으로 봐도 될까요? 비심인성 폐부종이나 폐렴과의 감별 포인트도 정리해 주세요.
```

화면 반응 (약 5초 + 스트리밍 6초):
단계 6개 — 질문 이해 → 작업 계획 → 흉부 영상 분석 (폐 분할 마스크 적용 · 근거

답변 구조:
- 서두: 양측 폐문부 중심 음영 + 심비대 + 기립 시 호전되는 호흡곤란 → 심인성 폐부종 81% [1][영상]
- 가장 유력: 심인성 폐부종 81%
- 확장 감별: 비심인성 폐부종(ARDS) — 발열 · 감염 징후 없음, BNP 정상이면 재고려 / 폐렴 27%
- 놓치면 안 됨: 흉수 동반 41% — 앙와위라 소량 흉수는 가려질 수 있음
- 추가 확인 제안: BNP · 심초음파, 이뇨제 투여 후 6-12시간 내 재촬영, 산소 공급

오른쪽 레일: 도구 실행 현황 (흉부 영상 분석 1회 · 문헌 검색 1회 · 임상 정보 분석
1회 완료), 확신도 점검 (합의 0.79 · 근거 충분 확정), 이 대화의 근거 3건.

나레이션 (답변이 끝난 뒤):
