# 프로토타입 시연 영상 대본 (무음 화면 녹화)

응급실에서 올라온 이동식 흉부 X-ray 한 건을 판독의가 Chest AI로 판독하는 흐름을
처음부터 끝까지 따라간다. 케이스는 `PX-2026-0125` (68세 남성, 급성 호흡곤란,
모델 출력 폐부종 81%). 나레이션 없이 화면만 녹화하므로 **화면 글을 읽을 시간을
남기고, 커서로 볼 곳을 가리키는 것**이 대본의 전부다. 총 4분 안팎.

## 준비

- 주소: https://26-hc-252.vercel.app (production). 로컬이면 `cd frontend && npm run dev`
- Chrome 새 탭으로 시작 (상태는 탭별 sessionStorage 라 새 탭 = 초기 상태).
  이미 쓰던 탭이면 사이드바 맨 아래 **세션 초기화** 클릭
- 북마크바 숨김 (`⌘⇧B`), 확대 100%, 창 폭 1440 이상. 브라우저 창만 녹화
- 녹화: `⌘⇧5` 화면 기록, 마이크 끔
- 커서는 천천히. 가리킬 때는 1초 멈춘다. 스트리밍 · 분석 중에는 움직이지 않는다
- 실수하면 그 씬만 다시 찍지 말고 세션 초기화 후 처음부터 (상태가 이어지는 구조)
- 아래 "체류" 는 그 화면에서 아무것도 안 하고 머무는 시간. 글이 많은 화면일수록 길다

## 상황

- 환자: 한지** 남성 68세. 어젯밤부터 누우면 심해지는 호흡곤란과 하지 부종.
  심부전 · 고혈압 과거력. 산소포화도 88%, 호흡수 28. 응급실 이동식 앙와위 AP 촬영
- 모델: CXR-NET v2.4 — 폐부종 81% · 심비대 63% · 폐 음영 58% · 흉수 41%

---

## 씬 0 — 진단 대시보드 (0:00 - 0:15)

화면: `/` 대시보드.

1. 체류 3초 (KPI · 우선 확인 카드 · 워크리스트가 한눈에)
2. 커서: 워크리스트 맨 아래 `PX-2026-0125` 행의 "분석 중" 칩 위에 1초
3. 클릭: 그 행 → 분류 분석으로 이동

자막 제안: 응급실에서 올라온 이동식 촬영, 분석 대기

---

## 씬 1 — 분류 분석 · 분석 실행 (0:15 - 1:05)

화면: `/analysis`. 왼쪽 필름 AP, 오른쪽 임상 정보.

1. 체류 4초. 커서: 오른쪽 임상 정보의 `88 %` (산소포화도) 와 증상 칩 위를 천천히 지나감
2. (선택) `+ 추가` 클릭 → `기좌호흡` 타이핑 → Enter. 칩이 추가됨
3. 클릭: **멀티모달 분석 실행**
4. 대기 약 4초: 영상 품질 확인 → 소견 분류 → 근거 영역 계산 → 임상 정보 결합.
   커서는 버튼 근처에 그대로
5. 결과가 뜨면 체류 6초. 커서: 이상 소견 지표 `84` → 소견 목록 `폐부종 의심 81%` →
   오른쪽 AI 판독 요약 순서로 1초씩
6. 클릭: 툴바 AI OVERLAY **히트맵** → 필름에 실제 Grad-CAM 과 외곽선 2개
7. 체류 4초. 커서: 왼쪽 필름의 실선 외곽선 → 오른쪽 LUNG FIELD 필름

자막 제안: 영상 + 임상 정보 동시 평가, 소견별 확률과 근거 영역

---

## 씬 2 — 근거 시각화 (1:05 - 1:40)

1. 클릭: 사이드바 **근거 시각화**
2. 체류 4초 (필름 4장: AP · OUTLINE / GRAD-CAM / EIGEN-CAM / LUNG MASK)
3. 클릭: AI OVERLAY `끄기` → 1초 → `외곽선` → 1초 → `히트맵`
4. 드래그: 불투명도 슬라이더를 오른쪽으로 살짝
5. 클릭: 대상 소견 칩 **심비대 의심 63%** → 2초 → **흉수 의심 41%** → 2초 →
   **폐부종 의심 81%**. 외곽선 위치와 오른쪽 표 강조 행이 따라 바뀜
6. 스크롤 아래로. 체류 5초. 커서: 임상 문장 기여도 첫 줄 `0.88` → 오른쪽 표
   `폐부종 의심 0.63 · 0.89` 행

자막 제안: Grad-CAM · Eigen-CAM · 폐 분할, 임상 문장 기여도와 위치 일치도

## 씬 3 — 진단 에이전트 · 3턴 (1:40 - 3:10)

1. 클릭: 사이드바 **진단 에이전트**. 빈 대화 화면 체류 2초

### 턴 1 — 감별 진단

2. 입력창에 타이핑 (일정한 속도로, 너무 빠르지 않게) 후 Enter:

```
68세 남성, 야간 발작성 호흡곤란과 하지 부종으로 응급실 내원. 양측 폐문부 중심 음영과 심비대가 보이는데 심인성 폐부종으로 봐도 될까요? 비심인성 폐부종이나 폐렴과의 감별 포인트도 정리해 주세요.
```

3. 대기: 단계 6개가 차례로 완료되고 답변이 써짐 (약 12초). 커서 정지
4. 답변이 끝나면 (하단에 시각 · CXR-NET V2.4 표시) 체류 8초.
   커서: 서두의 `[1]` `영상` 칩 → 가장 유력 / 확장 감별 / 놓치면 안 됨 버킷을 위에서
   아래로 → 오른쪽 레일 도구 실행 현황 → 확신도 점검 `0.79`

### 턴 2 — 촬영 조건 보정

5. 클릭: 후속 칩 **앙와위 AP 촬영이라 보정이 필요한 소견은?**
6. 대기 약 9초. 답변이 끝나면 체류 8초.
   커서: 보정 필요 버킷의 `심흉곽비 0.58` 줄 → 판독문 기재 제안

### 턴 3 — 치료 반응 · 재촬영 계획

7. 클릭: 후속 칩 **이뇨제 반응 평가를 위한 재촬영 시점과 호전 기준은?**
8. 대기 약 10초. 답변이 끝나면 체류 8초.
   커서: 재촬영 시점 버킷 → 추적 계획 4줄 → 오른쪽 확신도 `0.81 · 높음` →
   이 대화의 근거 목록
9. (선택) 맨 위 답변의 `6단계 실행 · 문헌 3편 인용` pill 클릭해 단계 펼쳤다가 다시 닫기

### 전환

10. 클릭: 답변 아래 틸 색 칩 **문헌에서 찾기 · 급성 심인성 폐부종 이뇨제 반응 평가와
    재촬영 시점** → 문헌 검색으로 이동

자막 제안: 판독의 질문 → 영상 · 문헌 · 임상 순으로 근거를 모아 답변, 근거 번호 연결

## 씬 4 — 문헌 · 사례 검색 (3:10 - 3:45)

화면: `/literature`. 검색창에 전환한 질문이 들어간 채 파이프라인이 자동 실행됨.

1. 대기 약 3초: STEP 01 → 04 순차 점등, 결과 4건 등장
2. 체류 6초. 커서: STEP 02 `후보 52건` → 결과 1번 가이드라인 배지 → 2번 논문 제목 →
   오른쪽 신뢰도 바 3개 → 근거 종합 콜아웃
3. 클릭: 2번 카드 **원문 열기** → 인용 정보 펼쳐짐. 체류 3초 → **닫기**
4. (선택) 검색창 내용 지우고 `폐부종 흉부 초음파 B-line 진단 정확도` 타이핑 → Enter →
   파이프라인 재실행, 결과 교체. 체류 4초

자막 제안: 하이브리드 검색 → 재정렬 → 근거 충분성 점검, 출처 등급과 신뢰도 3중 검증

## 씬 5 — 클로징 (3:45 - 4:00)

1. 클릭: 사이드바 **진단 대시보드**
2. 체류 4초. 커서: 우선 확인 카드가 한지** (폐부종 의심 81%) 로 바뀐 것 →
   워크리스트 0125 행 `우선 확인 · 84`
3. 클릭: 우측 상단 알림 아이콘 → "분석 완료 · 폐부종 의심 81%" 항목에 커서 2초
4. (선택) `⌘K` → 검사 검색 팔레트 2초 → ESC
5. 끝. 녹화 종료

자막 제안: 분석 결과가 워크리스트와 알림에 즉시 반영

## 자주 나오는 실수

- 답변이 나오는 중에 다음 칩을 누르면 무시된다. 하단 시각 표시가 뜰 때까지 기다린다
- 턴 1 을 타이핑 대신 스타터 칩 `심인성 폐부종으로 봐도 될까요? 감별 포인트는?` 으로
  대신해도 같은 답변이 나온다. 다만 무음 영상에서는 질문을 직접 타이핑하는 쪽이
  무엇을 물었는지 전달이 잘 된다
- 문헌 검색 화면에서 질문을 바꿔 Enter 하면 이전 결과는 사라지고 다시 검색한다
- 다른 케이스(0142 등)는 아직 샘플 필름이라, 이 대본은 0125 로만 찍는다
- 체류 시간이 길게 느껴져도 그대로 둔다. 편집에서 자르는 건 쉽고 늘리는 건 안 된다
