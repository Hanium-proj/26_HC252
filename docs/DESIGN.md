# Chest AI · Quiet precision

최신 사용자 디자인 요청에 따른 제품 규칙. `DESIGN-ref.md`는 사용자가 제공한 Apple 분석 원문이며 참고 자료다. 원문의 마케팅용 대형 여백을 그대로 복제하지 않고 검사 작업 흐름에 맞춰 적용한다. 이전 `frontend/DESIGN.md`의 틸·장식 그라데이션 규칙을 대체한다.

## 시각적 원칙

- 영상과 실제 근거가 중심. 흰색 작업 배경 `#ffffff`, 흰 표면, 단일 액션 블루 `#0066cc`.
- 장식 그라데이션·점선 박스·카드 그림자 금지. 팝오버에만 높이 표현.
- 주 행동 하나를 진하게, 보조 행동은 중성색. 성공·오류·경고는 상태 설명과 함께 사용.
- 본문 Pretendard Variable을 `next/font/local`로 자체 제공. 굵기 45–920 선언, 사용 굵기는 400/600/700. 본문 15px/1.6, 자간 0. 제목 자간 -0.02em, 줄 간격 1.25. keep-all + overflow-wrap:anywhere.
- 텍스트 세 단계: `--ink`, `--ink-2`, `--ink-3`. 보조 설명도 옅은 회색으로 묻히지 않게 유지. 본문 최소 대비 4.5:1, 주요 컨트롤 경계·포커스 3:1 확인.
- 모서리 토큰 28/20/14px. 패널 28, 내부 8px 여백이면 20. 최소 내부 반경 8. 알약·원형 컨트롤은 예외. squircle 지원 시 큰 카드만 40px 점진 적용.
- 구조 간격 4px 배수. 그룹 내부 8–16, 카드 24–32, 페이지 여백 40–48. 휴대폰은 좌우16.
- 애니메이션은 transform·opacity만. 컨트롤 180ms, 패널 200–300ms. 감속 곡선 cubic-bezier(.05,.7,.1,1). reduced-motion에서 모션과 부드러운 스크롤 제거.

## 작업 흐름

검사 선택은 모든 탭에서 유지한다. 분석 중/완료/실패를 텍스트로 알리고 완료 결과로 이동한다. 완료 결과 → 영상 근거 → 질문/문헌으로 연결하며 질문은 사용자 확인 후 전송한다. 키보드 탐색, 포커스 표시, 커스텀 선택창, 오류 재시도, 모바일 탐색을 유지한다. 실제 데이터와 결과에 장식용 가짜 수치를 넣지 않는다.

## 구현

색상은 `frontend/app/globals.css`의 단일 :root에서 정의한다. Tailwind는 변수 매핑만 한다. 외부 폰트 CSS 요청은 사용하지 않는다. 다크 모드는 이번 범위에 추가하지 않으며 영상 뷰어의 검정 배경만 유지한다.

참고: 사용자 Apple 분석 `docs/DESIGN-ref.md`, https://getdesign.md, https://github.com/orioncactus/pretendard . 폰트 라이선스는 `frontend/app/fonts/Pretendard-LICENSE.txt`에 동봉한다.

## 이번 검증

- 1270px 실제 브라우저 대시보드·대화 화면, 390px/768px iframe 안의 실제 앱 반응형 화면을 시각 확인.
- 검사 선택창 열기/Escape 닫기, 선택 검사 ID를 유지한 탭 이동 확인.
- 토큰 대비 계산: 본문/배경 15.46:1, 보조 본문 7.21:1, 메타/회색 표면 5.30:1, 액션/흰색 5.57:1, 입력 경계/흰색 3.33:1. 전체 WCAG 적합성 감사라는 의미는 아님.
- 외부 폰트 import 0, 단일 :root, 점선 border 없음. reduced-motion 규칙과 transform/opacity 전환 정적 확인.

## 탐색 및 브랜드 세부 개선

- 로고는 영상 프레임과 중앙 연결점을 결합한 자체 SVG, Chest AI 워드마크와 한글 설명으로 구성.
- 데스크톱 사이드바 240px/80px 전환, 버튼 및 ⌘/Ctrl+B 지원. 입력 필드에서는 단축키를 처리하지 않음. localStorage에는 접힘 여부만 저장하며 검사 데이터는 저장하지 않음. SSR은 펼친 상태로 일치시키고 hydration 이후 사용자 설정 복원.
- 접힌 메뉴에 접근성 이름·키보드/호버 툴팁·현재 메뉴 표시. 모바일은 별도 상단 메뉴 유지.
- 단계별 회색 타일 대신 번호와 현재 단계 밑줄 사용. 검사 선택 및 완료 배너를 축소하여 영상이 더 일찍 보이도록 조정.
- 검증: 실제 프로덕션 빌드에서 버튼 전환, 새로고침 복원, 키보드 툴팁, 검사 ID를 유지한 탭 이동, 단축키 펼치기 확인. lint/build 통과.

## 검사 검토 흐름 보완

- 워크리스트: 상태별 개수/필터, 파일명·최근순 정렬, 빈 결과 초기화. 검색·필터·정렬은 화면 이동 시 브라우저 세션 상태로 유지.
- 완료 검사의 결과 보기는 결과 섹션으로 직접 이동하고 포커스를 전달. 대기/진행 중 검사는 각각 분석 시작/진행 확인으로 구분.
- 추천 질문은 편집 가능한 초안에 먼저 입력. 완료된 답변의 복사 결과를 안내.
- 문헌 재검색 중 기존 결과 유지, 조건 변경 표시, 중지 및 완료 상태 안내. 중지 클릭의 기본 submit 동작을 막아 재전송 방지.
- 근거 화면은 등록 전/분석 전 상황별 설명 및 다음 행동 제공.
- 검증: lint/build, 실제 문헌 검색(4건 반환), 검색 중지, 상태 필터 초기화, 추천 질문 초안 포커스, 결과 직접 이동, 390px/768px 화면 확인.
