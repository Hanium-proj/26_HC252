단일 사용자 로컬 연구 작업 공간을 기준으로 실제 업로드 → 저장 → OpenAI 영상 설명 → 실제 DenseNet/PSPNet 실행 → CAM/분할 전달 → 실제 문헌 검색 → OpenAI SSE 답변과 후속 질문까지 검증했다. 고정 환자·미리 작성된 답변·가짜 확률·가짜 처리 시간은 실행 경로에서 제거했다.

## 검색 회귀 평가

기존 `eval_retrieval.py`의 8개 질문을 한국어·영어로 측정했다. 정답 문서는 제공된 코퍼스의 주제 메타데이터에 근거한다. **개발용 작은 회귀 세트이며, 이 세트의 결과를 보고 검색을 개선했으므로 독립 평가로 볼 수 없다.** 질의 번역은 생성 모델이어서 실행별 순위 변화가 가능하다.

| 최종 실행 | Hit@1 | Hit@5 | MRR@5 | 첫 검색 p50 |
|---|---:|---:|---:|---:|
| 한국어 8개 | 1.000 | 1.000 | 1.000 | 976.5ms |
| 영어 8개 | 0.875 | 1.000 | 0.9375 | 164.5ms |

초기 dense/BM25 RRF만 사용한 실행의 MRR은 두 언어 모두 0.875였다. 질환 메타데이터 범위, 문서 중복 제거, 낮은 관련도 제외를 반영했다. 인덱스 버전·질의·설정에 맞는 캐시를 사용하며, 관련도가 부족할 때 문헌을 억지로 채우지 않는다. 내부 캐시 조회는 최종 실행에서 약 0.64ms였다.

실제 실행별 상세 결과는 로컬 `backend/data/live/retrieval-evaluation.json`, 초기 결과는 `retrieval-evaluation-baseline.json`에 있다. 원문이 포함될 수 있는 로컬 산출물은 Git에서 제외했다.

## 현재 한계

- 독립 정답 원본 영상이 없어 AUROC·민감도·특이도·Dice·임상 효용은 측정하지 않았다. 메타데이터 CSV만으로 이 수치를 계산하지 않았다.
- 제공된 공개 가중치가 MIMIC 등을 학습에 사용했으므로 평가 데이터와 학습 환자의 중복을 확인해야 한다.
- 분류 점수는 보정된 질병 확률이 아니다. CAM은 모델 활성 지도이며 병변 분할이 아니다.
- 폐/심장 픽셀 폭 비율은 임상 CTR·병변 크기·mm 측정이 아니다. 해당 비율을 답변의 진단 근거로 넘기지 않는다.
- 실제 출처가 존재한다는 사실만으로 생성 문장의 해석까지 검증되지는 않는다. 출력은 판독의 검토용이며 문장 수준 근거 일치와 임상적 판단은 추가 평가가 필요하다.
- 원래 팀 모델 연결, 실측 크기, 장기 판독 이력 관리, 로그인·사용자별 격리·공유 운영은 현재 구현 범위 밖이다. 채팅 이력은 해당 화면의 대화 동안 유지하며 영구 판독 기록으로 저장하지 않는다.
- 파일 메타데이터 제거는 영상에 직접 찍힌 개인정보까지 자동 제거한다는 의미가 아니다.
- MIMIC 원문/인덱스는 접근 권한이 있는 로컬 환경에서만 사용한다. 임베딩 API에는 선택된 후보 판독문이 전달된다. 기관 정책과 데이터 이용 조건을 별도로 충족해야 한다.

독립 정답 데이터가 준비되면 `scripts/eval_classifier_manifest.py`로 환자 단위 AUROC/AP/민감도/특이도·추론 시간을 측정할 수 있다. 결과를 만들기 위해 정답 라벨이나 임상 검증 수치를 추정하지 않는다.
